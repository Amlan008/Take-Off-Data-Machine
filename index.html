METHOD

What is being corrected?

Each available Open-Meteo model is compared with the closest AWC METAR observation. Recent observations receive more influence, outlying errors are constrained, and each parameter is weighted by each model’s recent local skill. METAR variable winds are filled from the last actual direction or circularly interpolated between surrounding actual reports. Precipitation remains uncorrected because METAR does not supply a comparable amount.

Developer's Note

Despite remarkable advances in technology, nothing can replace the expertise, judgement, and experience of pilots and flight dispatchers. This simple tool has been created to make their work a little easier.
